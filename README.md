# MCR DESTROYER

Browser game 3D in terza persona ambientato in una control room MCR, costruito per funzionare online senza installare nulla.

## Comandi
- WASD: movimento
- Shift: corsa
- Spazio: salto
- Mouse: telecamera
- Click sinistro: mazzata
- R: reset sala
- H: aiuto

## Funzioni della v0.1
- Control room 3D procedurale ispirata al riferimento fotografico
- Personaggio in terza persona con mazza
- Videowall e monitor con stati integro / crepato / distrutto
- Sedie, tastiere, telefoni e rack con reazione fisica semplificata
- Vetri e banchi distruttibili
- Scintille e frammenti
- Contatore danni, combo e timer
- Supporto base touch
